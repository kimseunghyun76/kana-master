# v3 구조

v3는 기존 v2 앱을 삭제하거나 덮어쓰지 않고, 초보자 판매용 커리큘럼만 별도로 재구성하는 레이어입니다.

- `index-v3.html`: v3 진입점입니다. v2 학습 엔진을 재사용하지만 v3 데이터 파일을 먼저 주입합니다.
- `store.js`: `jp_master_v3` 저장 키를 사용합니다. v2 진행도와 섞이지 않습니다.
- `curriculum.js`: 여행 준비, N5 입문, 드라마 입문 중심의 새 모듈 순서입니다.
- `content-index.js`: 롤플레이를 한 상황씩 쪼개기 위한 v3 전용 대화 매핑입니다.
- `programs.js`: 7일 문자, 14일 생존 기초, 21일 여행, 30일 N5, 드라마 첫 귀 트기 프로그램입니다.
- `lecture-data.js`: v3에서 새로 쓰는 초보자용 강의 스크립트입니다.
- `module-visuals.js`: v3 모듈 ID에 맞춘 커버 이미지 매핑입니다.
- `app-shell.js`: v3 헤더명을 분리한 셸입니다. 나머지 화면/학습 플로우는 v2 엔진을 재사용합니다.

원칙:

- 한 강의는 한 주제만 다룹니다.
- 한 카드 묶음은 해당 강의에서 배운 표현과 난이도를 맞춥니다.
- 한 롤플레이는 한 상황만 다룹니다.
- IT/비즈니스 심화 과정은 v3 커리큘럼에서 제외합니다.

# v3 커리큘럼 개편안

목표 학습자: 일본어를 전혀 모르지만, 일본 여행에서 필요한 질문과 답변을 통째로 외워 바로 쓰고 싶은 사람.

## 핵심 설계

v3는 기존 v2를 유지한 채 별도 앱 진입점과 데이터 폴더로 운영한다.  
이번 방향은 문법 순서가 아니라 "여행 장면에서 실제로 듣고 답하는 말"을 중심으로 한다.

- 질문과 답변을 가장 중요한 학습 축으로 둔다.
- 사용자는 문법을 이해하기보다 먼저 통째로 외운다.
- 한 롤플레이는 한 상황만 다룬다.
- 약국, 병원, 공항, 지하철, 술집, 편의점, 옷가게, 식당, 호텔, 온천, 조식, 버스, 비행기, 공항 상점, 렌트카까지 확장한다.
- N5 문법은 별도 커리큘럼으로 빼지 않고 강의 팁과 문장 해설 안에 조금씩 녹인다.
- 검수 중에는 모든 강좌와 롤플레이를 잠그지 않는다.

## 11 STAGE 구조

1. 문자 입문
   - 오십음도 한눈에 보기
   - 히라가나 기본 46자
   - 가타가나 기본 46자

2. 읽기 규칙
   - 탁음, 반탁음
   - 요음과 작은 글자
   - 장음, 촉음
   - 조사 `は`, `へ`, `を`의 실제 발음

3. 질문·답변 핵심
   - 첫 인사와 리액션
   - 기본 물건과 장소
   - 대명사
   - 숫자, 시간, 돈, 수량
   - 방향, 장소, 신체부위
   - 질문하는 법
   - 대답하는 법
   - 리액션 쉐도잉

4. 공항·비행기
   - 공항 체크인
   - 입국 심사
   - 기내 요청
   - 공항 상점으로 이어질 기본 질문

5. 교통·길 찾기
   - 전철과 길 찾기
   - 버스 목적지 확인
   - 택시 이동과 결제

6. 먹고 마시기
   - 편의점
   - 카페와 조식
   - 식당 주문
   - 술집·이자카야

7. 쇼핑·결제
   - 옷가게와 사이즈
   - 상점 결제
   - 공항 상점·면세

8. 숙박·온천
   - 호텔 체크인
   - 객실 요청
   - 온천 이용 규칙

9. 건강·문제 해결
   - 약국
   - 병원 접수
   - 분실물과 도움 요청

10. 현지 확장
    - 렌트카
    - 관광지와 사진 부탁
    - 예약 확인
    - 날씨 때문에 일정 변경
    - 도움받은 뒤 마무리 감사

11. 드라마 귀 트기
    - 짧은 리액션
    - 감정 표현
    - 친구 말투와 정중체 차이
    - 짧은 일상 대사

## 상품 프로그램

- 7일 문자 완성
- 21일 생존 기초
- 30일 첫 일본 여행
- 14일 현지 확장
- 드라마 첫 귀 트기

## 롤플레이 비주얼 원칙

- 일본 현지 분위기가 바로 느껴지는 배경을 우선한다.
- 캐릭터는 기존 화자/캐릭터 자산을 활용하되 장면별로 다르게 배치한다.
- 공항, 교통, 음식, 쇼핑, 호텔·온천, 건강·문제 해결, 현지 관광 배경을 v3 전용으로 둔다.
- MP3 생성은 별도 단계로 두고, 현재는 화면 구성과 이미지/대화 데이터 검수를 우선한다.

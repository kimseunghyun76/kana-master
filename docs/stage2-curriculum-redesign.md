# Stage 2 Curriculum Redesign

## Goal

Redesign Stage 2 from topic-first survival content into a grammar-first N5 core plus survival usage layer.

Current Stage 2 is useful but too vocabulary-driven. The learner sees many scenarios before building stable sentence patterns.

This redesign makes Stage 2 the true beginner foundation.

## Design Principles

1. One module should teach one main sentence pattern.
2. Vocabulary exists to support sentence production, not the other way around.
3. Every module should end with guided output.
4. Every module should reuse previous grammar.
5. Every module should connect to one realistic travel or daily-life situation.

## Proposed Stage 2 Structure

### Module 1. Self-introduction and copula

Core grammar:

- `AはBです`
- `AはBではありません`
- `AはBですか`

Functions:

- saying who I am
- nationality
- occupation
- simple identity questions

Suggested vocab:

- name
- country
- company
- student
- engineer

Suggested roleplay:

- first meeting
- self-introduction

### Module 2. Demonstratives and possession

Core grammar:

- `これは〜です`
- `それは〜です`
- `これはAのBです`

Functions:

- pointing to objects
- identifying belongings
- asking what something is

Suggested vocab:

- this / that / which
- bag
- phone
- ticket
- passport

Suggested roleplay:

- airport desk
- hotel front desk

### Module 3. Basic particles

Core grammar:

- `は`
- `の`
- `も`
- `を`
- `と`

Functions:

- topic
- possession
- also
- object marking
- and / with

Suggested output:

- sentence reorder
- choose the correct particle
- build short identity and possession sentences

### Module 4. Numbers, prices, time

Core grammar:

- counters in simple high-frequency use
- `何時ですか`
- `〜時です`
- `〜円です`

Functions:

- asking price
- telling time
- reading store and transport information

Suggested roleplay:

- shopping
- booking
- appointment

### Module 5. Existence and location

Core grammar:

- `あります / います`
- `AはBにあります`
- `AはBにいます`

Functions:

- where things are
- where people are
- whether something exists

Suggested vocab:

- place words
- store
- station
- toilet
- hotel

Suggested roleplay:

- asking directions
- finding facilities

### Module 6. Adjectives and condition descriptions

Core grammar:

- `い` adjective present/past/negative
- `な` adjective + `です`
- simple comparisons in description

Functions:

- describing food
- describing places
- expressing preferences

Suggested roleplay:

- restaurant
- shopping recommendation

### Module 7. Verb polite forms

Core grammar:

- `ます / ません / ました`
- high-frequency verbs:
  - go
  - come
  - eat
  - drink
  - see
  - buy

Functions:

- simple actions
- daily schedules
- past actions

Suggested output:

- convert dictionary meaning into polite sentence
- answer simple diary prompts

### Module 8. Request and service language

Core grammar:

- `〜てください`
- `お願いします`
- `〜てもいいですか`

Functions:

- making requests
- asking for service
- asking permission

Suggested roleplay:

- restaurant ordering
- hotel requests
- convenience store interaction

## Required Step Template for Every Module

Each Stage 2 module should have:

1. Hook scene
2. Mini lecture
3. Target vocabulary
4. Controlled grammar drill
5. Listening or recognition quiz
6. Guided output
7. Dialogue preview
8. Roleplay

## Content Rules

- New target vocabulary per module:
  - 6 to 12 items
- New grammar targets per module:
  - 1 major
  - 1 minor max
- Review items:
  - at least 30 percent of the module

## Assessment Rules

- Module completion requires passing quiz threshold
- Roleplay completion should require at least one output-bearing activity
- SRS due review should be fed from both vocab and grammar-sensitive prompts

## Definition of Success

Stage 2 is successful when a learner can:

- introduce themselves politely
- ask and answer simple questions
- read basic signs and prices
- ask where things are
- order, request, and confirm simple services
- produce short correct sentences without relying only on recognition

  3. 타 기기 접속이라면 --host 0.0.0.0 옵션 필요

② 라이브러리 설치
pip install edge-tts flask flask-cors ③ 서버 실행
python edge_tts_server.py 앱 폴더의 edge_tts_server.py 파일 사용

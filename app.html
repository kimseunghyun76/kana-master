🔊 음성 엔진
비활성
VOICEVOX(로컬 설치)가 실행 중일 때 사용 가능. 미사용 시 Web TTS 사용.
① VOICEVOX 다운로드 · 설치
https://voicevox.hiroshiba.jp/ → 무료 다운로드 → 설치

② VOICEVOX 실행
앱을 실행하면 자동으로 localhost:50021 서버 시작

③ CORS 허용 (중요)
VOICEVOX 메뉴 → エンジン → HTTPサーバーを起動 확인
또는 바로가기 속성에 아래 옵션 추가:
VOICEVOX.exe --host 0.0.0.0 --allow-origin "*" ④ 연결 확인
브라우저에서 http://localhost:50021/speakers 접속 → JSON 표시되면 정상

⑤ 이 설정에서 VOICEVOX 사용 토글 ON → 화자 목록 자동 로드
💡 화자 A=👨남자, 화자 B=👩여자 (고정)
🎭 캐릭터 이름 설정
스크립트 {M}=남자, {F}=여자 자리에 표시될 이름

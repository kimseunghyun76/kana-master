# v3 Product Rebuild Plan

목표는 "일본어를 전혀 모르는 사용자가 여행 준비, N5 입문, 드라마 첫 귀 트기를 순서대로 해내는 앱"이다.

## 고정 원칙

- 첫 화면은 `오십음도 → 히라가나 → 가타가나 → 읽기 규칙` 순서로 시작한다.
- 전체 퀴즈는 해당 글자 묶음을 모두 배운 뒤에만 나온다.
- 질문과 답변은 별도 이해 과목이 아니라 모든 여행 장면의 핵심 반복축으로 둔다.
- 한 롤플레이는 한 상황만 다루고, spoken line 기준 최소 10개 대사를 목표로 한다.
- 카드 학습은 한 묶음 10~19개로 제한해 너무 얇거나 너무 무거운 세트를 피한다.
- N5 문법은 독립 코스로 밀어내지 않고 조사, 질문, 대답, 숫자, 날짜, 장소 표현 안에 녹인다.
- IT/비즈니스 심화는 current-v3 상품 커리큘럼에서 제외한다.

## 작업 순서

1. 문자 입문과 읽기 규칙을 정돈한다.
2. 첫 인사 전 기본 재료를 `대명사, 장소, 숫자, 방향, 신체, 질문, 대답, 리액션`으로 재배열한다.
3. 여행 장면별 롤플레이를 최소 10대사 기준으로 확장한다.
4. 강의, 카드, 롤플레이의 문장/단어가 같은 목표를 보도록 맞춘다.
5. 이미지/캐릭터는 강의와 롤플레이를 분리해 배치한다.
6. MP3 생성 전 `npm run audit:v3`로 얇은 카드, 짧은 롤플레이, 조기 퀴즈를 점검한다.
